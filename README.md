# Pokemon

## Description

Pokemon is a web application showcasing a list of 150 original Pokemon, envisioned with a solar punk aesthetic. Built using React, this project aims to provide a visually engaging and informative experience for Pokemon enthusiasts.

## Installation

To get started with the Pokemon project, follow these steps:

1.  Clone the repository:

    ```bash
    git clone https://github.com/Andrewcoder43/Pokemon.git
    ```

2.  Navigate to the project directory:

    ```bash
    cd Pokemon
    ```

3.  Install the dependencies:

    ```bash
    npm install
    ```

## Usage

1.  Start the development server:

    ```bash
    npm start
    ```

    This will launch the application in your default web browser.

2.  Build the project for production:

    ```bash
    npm run build
    ```

    This will create an optimized build of the application in the `build` directory.

3.  Deploy the project:

    ```bash
    npm run deploy
    ```

    This command uses `gh-pages` to deploy the built project to GitHub Pages. Ensure that you have configured GitHub Pages for your repository.

## Features

-   **Display of 150 Original Pokemon**: A curated list of the first generation Pokemon.
-   **Solar Punk Aesthetic**: A unique visual style blending technology and nature.
-   **React-Based**: Built using React for a dynamic and responsive user interface.
-   **Component-Based Architecture**: Utilizes reusable React components for maintainability and scalability.
